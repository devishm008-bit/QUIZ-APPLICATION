# Python Quiz Application 🎯

A beginner-friendly quiz application built using Python that tests users' Python knowledge through multiple-choice questions.

## Features
- Three difficulty levels: Easy, Medium, and Hard
- Multiple-choice questions
- Automatic answer checking
- Score calculation and percentage
- Performance feedback
- Input validation

## Technologies Used
- Python 3
- Lists and Dictionaries
- Loops and Conditional Statements
- String Formatting

## How to Run
1. Install Python 3.
2. Download `QUIZ.PY` from this repository.
3. Open a terminal in the folder containing the file.
4. Run:

   `python QUIZ.PY`

This project helped me practise Python fundamentals, including loops, dictionaries, conditional statements, user input, and basic program logic.
